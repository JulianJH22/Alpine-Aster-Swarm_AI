# Fase 6.3.3.4 — BC sintético y evaluación híbrida

## Ruta rápida (reutilizar las 68 observaciones de la fase anterior)

Desde `sim/`:

```bash
export SWARM_IK_STRIDE=4
python pretrain_bc_6334.py --reuse-anchors out/bc6333/demonstrations.npz --samples 10000 --epochs 60 --out out/bc6334
python evaluate_hybrid_6334.py --checkpoint out/bc6334/bc_actor_best.pt --agents 1 --episodes 10
```

Si no tienes el archivo anterior, omite `--reuse-anchors` para recopilar 40 episodios.

**Importante:** los 10 000 ejemplos sintéticos son aproximaciones geométricas; NO equivalen a 10 000 experiencias físicas. Se divide por anclas antes de sintetizar para reducir fuga entre entrenamiento y validación. La validación MSE no sustituye a la evaluación física.

El evaluador compara el profesor, mezclas con 25 % y 50 % de actor, y actor puro, en las mismas semillas. Las mezclas NO son una política MAPPO entrenada; son un modo de control híbrido para evaluar viabilidad. Si el profesor gana, úsalo para movimiento básico y reserva RL para coordinación. No activar la mezcla en `train_mappo_63.py`: las probabilidades de acción PPO no serían válidas sin adaptar el cálculo de log-probabilidad.

Después de evaluar, revisa `out/bc6334/report.json` y `out/bc6334/evaluation.json`. Si el actor puro supera al original, puedes iniciar MAPPO:

```bash
python train_mappo_63.py --bc-actor out/bc6334/bc_actor_best.pt --episodes 60 --eval-every 20 --eval-episodes 3 --out out/mappo_bc6334
```
