# Roadmap — Alpine Aster

## Hackathon demonstration
- Six-arm PyBullet industrial-cell simulation
- Scripted stabilization, disassembly, and sorting
- Rotating six-sector platform and conveyor-belt outputs
- BC/MAPPO research for local TCP positioning
- Control interface prepared for future AI integration

## Next milestones
1. Physically validated grasping and component extraction
2. Collision-aware multi-arm task scheduling
3. Learning tasks for grasping, extraction, handoffs, and sorting
4. AI policy integration with the simulation control interface
5. Robustness evaluation across seeds and task configurations

The current demonstration is choreographed, not autonomous disassembly.
